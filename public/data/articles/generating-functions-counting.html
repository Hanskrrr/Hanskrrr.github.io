In One Sentence

生成函数把“某种结果的大小”编码成幂次，把“得到该结果的方法数”编码成系数，让分配律枚举选择、指数相加合并大小、系数相加累计方法数。

    B --> C[为每类选择建立一个因子]
    C --> D[相乘组合独立选择]

这里采用普通生成函数，以硬币组合计数为例。与微分的连接见 导数与微分为什么描述一阶变化 和 对偶数为什么能计算一阶导数。

Explanation

先定义“不同方法”

有 111 元、222 元、555 元三种面额，每种数量不限。目标是凑出 555 元。

计数约定是：同面额硬币不区分个体，拿取顺序不影响结果。因此“先拿 111 元再拿 222 元”与相反顺序是一种方法。一种方案完全由三种面额各拿多少枚确定。

如果问题改为区分硬币个体、考虑拿取顺序、或允许负金额操作，编码也必须随之改变，不能直接复用同一个乘积。

用幂次与系数分工记录信息

规定：

G(x)=c0+c1x+c2x2+⋯ ,G(x)=c_0+c_1x+c_2x^2+\cdots,G(x)=c0​+c1​x+c2​x2+⋯,

其中 cnc_ncn​ 表示得到金额 nnn 的方法数。xxx 是形式变量，不需要给它一个数值；幂次记录金额，系数记录方案数量。

仅考虑 111 元硬币：

1+x+x2+x3+⋯ .1+x+x^2+x^3+\cdots.1+x+x2+x3+⋯.

选项 xkx^kxk 表示拿 kkk 枚 111 元硬币；常数项 1=x01=x^01=x0 表示拿零枚，这也是一种合法选择。

仅考虑 222 元硬币：

1+x2+x4+x6+⋯ .1+x^2+x^4+x^6+\cdots.1+x2+x4+x6+⋯.

选项 x2kx^{2k}x2k 表示拿 kkk 枚 222 元硬币。同理，555 元硬币对应：

1+x5+x10+⋯ .1+x^5+x^{10}+\cdots.1+x5+x10+⋯.

每个选项的系数都是 111，因为对单个面额而言，指定数量就指定了一种选择。

为什么相乘就会枚举组合

将三个因子相乘：

G(x)=(1+x+x2+⋯ )(1+x2+x4+⋯ )(1+x5+x10+⋯ ).G(x)=(1+x+x^2+\cdots)(1+x^2+x^4+\cdots)(1+x^5+x^{10}+\cdots).G(x)=(1+x+x2+⋯)(1+x2+x4+⋯)(1+x5+x10+⋯).

分配律要求从每个因子中选择一项，再把选中的项相乘。例如：

x3⋅x2⋅1=x5x^3\cdot x^2\cdot1=x^5x3⋅x2⋅1=x5

表示三枚 111 元、一枚 222 元、零枚 555 元。指数相加，正好对应金额相加。

另一组硬币数量若也得到金额 555，就会产生另一个 x5x^5x5。合并同类项时，这些贡献相加，于是 x5x^5x5 的系数就是全部方案数。

这个对应必须可逆：每种合法的硬币数量组合对应一组因子选项，每组选项也对应一种合法方案。若编码重复表示同一方案，系数就会重复计数；若遗漏选项，系数就会少算。

系数乘法实际执行的是卷积

设一类选择的生成函数为 A(x)=∑i≥0aixiA(x)=\sum_{i\ge0}a_ix^iA(x)=∑i≥0​ai​xi，另一类为 B(x)=∑j≥0bjxjB(x)=\sum_{j\ge0}b_jx^jB(x)=∑j≥0​bj​xj。合并后：

[xn](A(x)B(x))=∑i=0naibn−i.[x^n]\bigl(A(x)B(x)\bigr)=\sum_{i=0}^{n}a_i b_{n-i}.[xn](A(x)B(x))=i=0∑n​ai​bn−i​.

[xn][x^n][xn] 表示提取 xnx^nxn 的系数。对每种金额分拆 n=i+(n−i)n=i+(n-i)n=i+(n−i)，第一类有 aia_iai​ 种选择，第二类有 bn−ib_{n-i}bn−i​ 种选择，两者搭配有 aibn−ia_ib_{n-i}ai​bn−i​ 种；再把所有分拆的贡献相加。

这就是系数卷积。乘积法则的组合意义是“每种第一类选择都能与每种第二类选择搭配”；若两类选择互相制约，就需要额外编码或修改因子。

Example

用系数求出 555 元的四种组合

Boundaries and Common Confusions

为什么可以在每一步截断

只关心金额不超过 NNN 时，可以把每次运算结果截断为：

c0+c1x+⋯+cNxN.c_0+c_1x+\cdots+c_Nx^N.c0​+c1​x+⋯+cN​xN.

其依据是所有项的次数都非负。一个已经超过 NNN 次的项再乘任何非负次项，次数只会增加；加法也不会把它变成更低次项。因此删掉它不会改变目标范围内的系数。

代数上，这相当于在模 xN+1x^{N+1}xN+1 的截断多项式结构中计算，把 xN+1x^{N+1}xN+1 及更高次项视为零。这是更换记录系统后的规则，不是宣称普通实数 xxx 满足该等式。

如果允许负次幂，就不能沿用上述证明：例如 xN+1x−1=xNx^{N+1}x^{-1}=x^NxN+1x−1=xN，高次项可能重新影响目标范围。同样不能随意除以 xxx；截断规则只对所采用的合法运算成立。

形式幂级数的每个目标系数还必须是有意义的有限计数。正面额、有限种类的硬币满足这一要求；若允许无限枚零面额硬币，固定金额可能已有无限种数量组合，原计数模型必须调整。

生成函数与对偶数共享什么机制

一个可复用的连接是：先用幂次和系数记录关心的信息，再选择不会破坏目标信息的截断规则，使代数运算直接完成原问题的组合。

对偶数只保留常数项和一次项，规定 ε2=0\varepsilon^2=0ε2=0：

(a+bε)(c+dε)=ac+(ad+bc)ε.(a+b\varepsilon)(c+d\varepsilon)=ac+(ad+bc)\varepsilon.(a+bε)(c+dε)=ac+(ad+bc)ε.

这里 ad+bcad+bcad+bc 正是一般卷积公式在一次项上的特例。只可能由“零次乘一次”或“一次乘零次”产生，一次乘一次已经属于被截断的二次项。

但两者不能完全等同：

场景 幂次记录什么 系数记录什么
硬币生成函数 金额 对应金额的方案数
对函数作形式扰动展开 扰动阶数 该阶扰动的系数
对偶数自动微分 只保留零阶与一阶 当前值与一个方向上的变化率

对多项式 fff，展开 f(a+bt)f(a+bt)f(a+bt) 后，一次项系数由导数定义可解释为 f′(a)bf'(a)bf′(a)b。对一般可微函数，只能普遍保证：

f(a+bt)=f(a)+f′(a)bt+o(t),f(a+bt)=f(a)+f'(a)bt+o(t),f(a+bt)=f(a)+f′(a)bt+o(t),

不能假设一定存在完整的无穷幂级数。基本函数需要提供与微分相容的对偶数扩展，复合计算的正确性由链式法则保证，详见 对偶数为什么能计算一阶导数。

计数模型比表达式更先确定

  • 同面额的硬币数量方案与有顺序的硬币序列，是不同的计数对象。本笔记的乘积计数前者。
  • 系数不总是 111。若一个局部因子中有三种不同选择都产生金额 ddd，它们应贡献 3xd3x^d3xd。
  • 形式变量并不是概率、金额或导数本身；其用途由编码约定决定。
  • “高阶信息不会影响低阶信息”依赖合法运算与非负次数的条件，不能当作所有代数表达式的无条件性质。

When This Is Useful

当方案由若干类选择组成、每类都有可列出的贡献量、总贡献由相加得到时，可以尝试生成函数：先明确每个方案怎样对应因子选项，再让多项式乘法处理组合与计数。

它也为理解对偶数提供了有效入口：对偶数的乘法不是神秘的新公式，而是只保留前两个系数的多项式乘法；微积分再解释其中一次项为什么是导数。生成函数负责提供代数直觉，导数与微分为什么描述一阶变化 负责说明变化率的数学含义。

Active Recall

  1. 硬币因子里的常数项 111 表示什么？
    • 答：该面额拿零枚，是一种合法选择；不是“没有方案”。如果必须拿至少一枚，就要去掉这项。
  2. 为什么乘积的 xnx^nxn 系数会等于方法数？
    • 答：每次从各因子选一项对应一个合法方案，指数相加得到总金额，同金额的贡献经合并同类项相加。需要保证方案与因子选项之间一一对应。
  3. 卷积公式 ∑i=0naibn−i\sum_{i=0}^{n}a_i b_{n-i}∑i=0n​ai​bn−i​ 怎样解释？
    • 答：枚举两部分金额之和为 nnn 的所有分拆；对每种分拆，独立选择数相乘；最后把互不重复的分拆贡献相加。
  4. 为什么凑 NNN 元时可以丢掉高于 NNN 次的项？
    • 答：所有金额非负，后续加乘不能把高次项降到目标次数。若引入负次幂或除以形式变量，这个理由就失效。
  5. ε2=0\varepsilon^2=0ε2=0 与硬币问题中截断到 NNN 次的关系是什么？
    • 答：前者是只保留零次和一次项的截断代数，后者保留零次到 NNN 次；二者共享系数运算和截断机制，但系数解释不同。
  6. 生成函数类比能否单独证明任意函数接受对偶数后的求导公式？
    • 答：对多项式可直接按代数展开证明；对一般可微函数仍需一阶微分定义与链式法则，不能未经说明假设完整 Taylor 级数存在。
