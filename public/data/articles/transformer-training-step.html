In One Sentence

一次语言模型训练是：将一小批 token 序列右移为预测目标，前向计算所有位置的词表概率，只对真实位置计算交叉熵，再将误差反向传播并更新长期保存的模型参数。

Explanation

以 decoder-only 语言模型为例，对 token 序列 [x0,x1,…][x_0,x_1,\ldots][x0​,x1​,…]，输入与目标错开一位：当前位置读取 xix_ixi​，目标是 xi+1x_{i+1}xi+1​。例如：

input:  [BOS, 我, 爱, 猫]
target: [我, 爱, 猫, EOS]

若 batch 中样本长短不同，短序列补上 [PAD] 以组成矩形，并用 padding mask 标识真实位置。[PAD] 不应被 Attention 读取，且不应参与 loss。

flowchart LR
    A[Input IDs]
    --> B[Token Embedding<br/>+ Position Embedding]
    --> C[Transformer Blocks]
    --> D[Final Norm]
    --> E[Vocabulary Logits]
    --> F[Softmax Probabilities]

对 batch 中每个真实位置，交叉熵为：

−log⁡P(correct token)-\log P(\text{correct token})−logP(correct token)

这个负对数目标的概率依据见 交叉熵损失为什么是负对数似然；softmax 与交叉熵如何把预测误差变成 logits 和参数梯度，见 Softmax 与交叉熵的梯度为什么是预测减目标。

所有真实位置的 loss 取平均。反向传播计算每个参数对 loss 的影响方向；优化器据此更新 embedding、Attention 投影、FFN、Norm 参数和词表输出层。最简更新模型是：

θ←θ−η∇θLoss⁡\theta\leftarrow\theta-\eta\nabla_\theta\operatorname{Loss}θ←θ−η∇θ​Loss

实践中常用 AdamW 一类优化器，它会结合历史梯度统计决定更新幅度。

在常见的 Pre-Norm decoder block 中，一层的核心数据流可写成：

U=H+MHA⁡(LN⁡(H))U=H+\operatorname{MHA}(\operatorname{LN}(H))U=H+MHA(LN(H))
Hnext=U+FFN⁡(LN⁡(U))H_{next}=U+\operatorname{FFN}(\operatorname{LN}(U))Hnext​=U+FFN(LN(U))

MHA 的输出对每个 token 已汇总可见上下文；FFN 再对所有 token 并行计算，但逻辑上逐 token 独立、共享同一组参数。因此 token 间信息交换发生在 Attention，而不是 FFN 内部。Norm 的作用与选择边界见 Transformer 中的归一化为什么重要。

Example

设 batch size 为 2，最大长度为 4：

input_ids =
[[BOS, 我, 爱, 猫],
 [BOS, 他, 笑, PAD]]

target_ids =
[[我, 爱, 猫, EOS],
 [他, 笑, EOS, PAD]]

padding_mask =
[[1, 1, 1, 1],
 [1, 1, 1, 0]]

这批数据有 7 个真实预测目标。若隐藏维度为 DDD、词表大小为 VVV，常见张量形状为：

input_ids:  [2, 4]
hidden H:  [2, 4, D]
logits:    [2, 4, V]
targets:   [2, 4]

训练循环可概括为：

optimizer.zero_grad()
logits = model(input_ids, padding_mask)
loss = cross_entropy(logits, target_ids, ignore_index=PAD_ID)
loss.backward()
optimizer.step()

Boundaries and Common Confusions

  • 训练时所有位置可并行计算，是因为 causal mask 阻止每个位置读取未来 token；并行不等于泄漏答案。
  • 模型参数是跨 batch 保留并逐步更新的数字；Q、K、V、attention weights、logits 等是当前 batch 临时产生的中间结果。
  • 生成阶段没有 target、loss 或参数更新；模型选出一个新 token，追加到输入后再运行下一步。
  • 本笔记描述的是 decoder-only 语言模型。encoder-only 和 encoder-decoder 模型会改变可见范围或加入 cross-attention，但仍有前向、loss、反向和更新这条基本训练链路。

When This Is Useful

用于把 tokenizer、mask、Transformer block、词表概率、loss、反向传播和优化器放在同一次参数更新中理解。

Active Recall

  • Question: 为什么 target 序列相对 input 序列右移一位？
    • Answer: 语言模型在每个位置学习预测下一个 token；当前位置的输入不应直接包含其要预测的目标。
  • Question: 一次 training step 中哪些量会长期保留？
    • Answer: 模型参数及优化器状态；当前 batch 的中间张量在该步结束后不再作为模型状态保留。
