Scope

当前整理范围是正则表达式、ε-NFA、DFA 之间保持语言的转换，以及克林定理的两个方向。图中的语言均为有限字母表上的有限字符串集合。

Knowledge Structure

flowchart TD
    theorem["克林定理：表达力相同"] --> forward["正则表达式到 DFA"]
    forward --> thompson["按表达式结构构造 ε-NFA"]
    thompson --> subset["用状态集合确定化"]
    theorem --> backward["DFA 到正则表达式"]
    backward --> gnfa["添加新起终点并使用正则边标签"]
    gnfa --> eliminate["消除状态并保持路径语言"]

该图组织证明步骤，箭头表示证明分支及构造顺序，不表示一个机器模型是另一个模型的子类型。

Learning Path

  1. 正则表达式与有限自动机为什么等价：明确要证明的两个量词命题，并完成表达式到 ε-NFA 的结构归纳。
  2. NFA 到 DFA 的子集构造：理解 ε-闭包、转移公式和读完任意前缀后的状态集合不变量。
  3. DFA 到正则表达式的状态消除：理解正则边标签如何记录被删状态的路径。

Important Relationships

  • 三篇笔记使用同一个语言“以 a 结尾的二元字符串”，方便核对转换前后的接受行为。
  • 集合的势、可数性与枚举 给出有限字符串的枚举基础；幂集、函数集与康托尔对角线论证 帮助分清有限状态幂集与无限集合幂集。
  • 同一语言可以对应多个正则表达式和多个 DFA。表达力相同不意味着表示唯一或表示规模相同。
