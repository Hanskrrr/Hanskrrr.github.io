一次请求的过程

浏览器打开一个网址时，会先向服务器请求这个地址对应的文件。在静态网站中，服务器返回的是提前准备好的 HTML 文件。浏览器读取其中的标记，继续下载样式表、脚本和图片，再将这些内容组合成你看到的页面。

静态不等于没有交互

“静态”描述的是服务器提供文件的方式。筛选文章、切换主题、运行终端、播放声音，都可以由浏览器中的 JavaScript 完成。这个演示中的交互就在你的浏览器里运行。

部署时发生了什么

开发者先在本地修改文件并预览，再把需要公开的文件提交到仓库。GitHub Pages 根据配置发布这些静态文件。访问者获得的是发布后的网页资源，并不会获得开发者电脑上的所有文件。

公开文件的边界

凡是浏览器能够直接下载的公开文件，都可以被保存和检查。隐藏按钮或者不展示链接，只能改变发现内容的路径。需要保密的原稿必须先在本地加密，再上传密文。
