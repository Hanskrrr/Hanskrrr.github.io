In One Sentence

Transformer FFN 先把每个 token 表示改写为许多中间特征，借由非线性按输入选择哪些特征参与，再把这些特征合成为对原 token 表示的 dmodeld_{model}dmodel​ 维修改量。

矩阵乘法可同时从三个角度理解：

  1. 并行特征探测器：WupW_{up}Wup​ 的每一行与 xxx 点积，得到一个可学习特征的强度。
  2. 可学习坐标系：矩阵把输入从原来的坐标描述改写到模型训练得到的特征坐标描述。
  3. 线性几何变换：矩阵可旋转、缩放、剪切或压缩向量空间，但本身不能根据输入选择不同规则。

Boundaries and Common Confusions

  • FFN 对所有 token 一起进行矩阵计算，但逻辑上是逐 token、共享参数的：不同 token 不会在 FFN 内直接相互读取。
  • 上投影与下投影是工程术语，通常表示线性映射，不一定是严格线性代数意义的正交投影。
  • Attention 负责 token 间的信息交换；FFN 负责单个 token 内的非线性特征加工。
  • 现代模型可能使用 SwiGLU 等门控 FFN，而非传统的 GELU FFN；其数据流思想相同，但激活方式不同。
