In One Sentence

归一化不是让文本“标准化”，而是让深层网络送入 Attention 和 FFN 的 token 向量保持可控的数值尺度；Transformer 通常采用逐 token 的 LayerNorm 或 RMSNorm，并通过 residual 保留原表示的主信息通路。

Explanation

每层都会把 token 向量乘以可学习矩阵并做非线性变换。训练持续更新这些矩阵，因此不同层的输出可能逐渐过大或过小。对 Attention 而言，向量尺度会直接影响 q⋅kq\cdot kq⋅k：分数过大时 softmax 几乎只选一个位置；分数过小时，权重趋于平均。深层 residual 叠加也会放大这种数值不稳定。

对一个 token 向量 h=[2,4,6]h=[2,4,6]h=[2,4,6]，LayerNorm 只在这个 token 的特征维度内计算均值与方差：先减去均值 444，再按自身标准差缩放。它不会读取同一句的其他 token，也不依赖 batch 中其他句子。

LayerNorm 作用于送进子层的副本，而 HHH 或 UUU 经 residual 直接加回。因此归一化带来的尺度控制不等于删除原 token 表示。

为什么不是默认使用 BatchNorm

BatchNorm 为同一特征收集一个 mini-batch 内多个样本的统计量；推理时通常改用训练期累计的统计量。对变长文本，一个 batch 要靠 [PAD] 补成矩形。若把 padding 位置计入统计量，结果会受无意义补位影响；若排除它，又需要额外的掩码处理。更根本地，同一个 token 的输出会依赖恰好与它同批出现的其他句子。

LayerNorm 只处理当前 token 的内部特征，因此 batch 大小、句长和同批样本组成不会改变其定义。这使它特别适合作为 Transformer 的默认选择。BatchNorm 并非不能用于序列模型；它只是更自然地适合批统计稳定的场景，例如常见 CNN 训练。

RMSNorm

RMSNorm 只按均方根缩放，而不减去均值：

它保留 token 向量的整体均值，计算也更简单。它不是在所有任务上理论上必然优于 LayerNorm，而是一个常见的稳定性、表达与计算成本权衡。

Example

对一个 batch，[PAD] 是补齐用的空位。假设某个特征在五个真实 token 上的值为 1, 2, 4, 3, 0，均值为 222；若额外把一个 padding 的 0 一并计入，均值就变成 10/6≈1.6710/6\approx1.6710/6≈1.67。这说明 batch 范围的统计量会被补位方式改变。

相对地，LayerNorm 处理单个 token [1,3] 时只得到它自己的均值 222，与 batch 中还有多少句子或 padding 无关。

Boundaries and Common Confusions

  • LayerNorm 的目标不是保证每层输出永久服从正态分布，而是给子层输入提供较稳定的数值尺度。
  • LayerNorm 确实移除了每个 token 的整体均值与尺度；Pre-Norm 的 residual 通路让原表示仍可直接向后流动。
  • BatchNorm、LayerNorm 与 RMSNorm 的核心区别是统计量计算的轴，而非是否存在 γ\gammaγ、β\betaβ 一类可学习参数。
  • padding mask 还必须用于 Attention 和 loss；LayerNorm 不依赖 batch 统计量并不自动替代 mask。

Active Recall

  • Question: 为什么 q⋅kq\cdot kq⋅k 的数值尺度会影响 Attention？
    • Answer: softmax 对分数尺度敏感；过大使权重过尖锐，过小使权重接近平均。
  • Question: Pre-Norm 为什么不会简单地“洗掉” token 的原信息？
    • Answer: 子层读取归一化副本，但 residual 将未归一化的输入直接加回输出。
  • Question: 对变长文本，BatchNorm 的统计为什么可能受 padding 影响？
    • Answer: 它跨 batch 收集统计量；补齐位置若被计入会改变均值和方差，若不计入则需要额外掩码逻辑。
