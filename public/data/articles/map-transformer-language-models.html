Scope

组织 Transformer 语言模型的完整数据流：token 如何成为向量，token 如何经由注意力和 FFN 更新，以及一次训练如何把预测误差转化为参数更新。

Learning Path

  1. Transformer 的一次训练如何进行：先建立一次训练中的数据、张量形状、损失和更新过程。
  2. Transformer 中的归一化为什么重要：理解为什么深层 block 需要控制 token 向量的数值尺度。
  3. 自注意力中的因果掩码与多头输出：理解 token 间的信息读取、掩码和 head 的汇合。
  4. Transformer FFN 的 projection up 与 projection down：理解每个 token 如何在 Attention 后独立加工其上下文表示。

Foundations

Important Relationships

  • 训练中的概率目标见 交叉熵损失为什么是负对数似然，误差如何进入参数更新见 Softmax 与交叉熵的梯度为什么是预测减目标；两者共同补充 Transformer 的一次训练如何进行。

  • Attention 在 token 之间传递信息；FFN 在每个 token 内部变换特征。

  • FFN 后的 token 表示会成为下一层 self-attention 的 Q、K、V 来源。

  • Causal mask 限制 decoder 只能读取当前位置及过去的位置，使 next-token 训练不泄漏未来答案。
