对多项式函数，给输入增加一个真实扰动：

f(2+t)=10+7t+t2,f(2+3t)=10+21t+9t2.f(2+t)=10+7t+t^2,\qquad f(2+3t)=10+21t+9t^2.f(2+t)=10+7t+t2,f(2+3t)=10+21t+9t2.

要得到一次项，只能选择零次乘一次或一次乘零次。非负幂的加乘不会把二次项降回一次项。用 T1T_1T1​ 表示保留前两项，便有：

#include <cmath>

struct Dual { double value, tangent; };

Dual operator+(Dual x, Dual y) {
    return {x.value + y.value, x.tangent + y.tangent};
}
Dual operator*(Dual x, Dual y) {
    return {x.value * y.value,
            x.tangent * y.value + x.value * y.tangent};
}
Dual operator/(Dual x, Dual y) { // precondition: y.value != 0
    return {x.value / y.value,
            (x.tangent * y.value - x.value * y.tangent)
                / (y.value * y.value)};
}
Dual exp(Dual x) {
    double v = std::exp(x.value);
    return {v, v * x.tangent};
}
Dual F(Dual x) {
    return exp(x * x) / (Dual{1.0, 0.0} + x);
}
// F({1.0, 1.0}) returns {e / 2, 3 * e / 4}.

Boundaries and Common Confusions

  • a+bεa+b\varepsilona+bε 并非把真实速度作为位移加到位置上。它保存两个系数；路径语义只是对这两个系数的一种一致解释。
  • dfa(b)df_a(b)dfa​(b) 可以对任意固定 bbb 精确求值，但通常不等于有限差 f(a+b)−f(a)f(a+b)-f(a)f(a+b)−f(a)。
  • 一般可微函数只要求余项 o(t)o(t)o(t)；不能一概把余项写成二次多项式或假定无限 Taylor 展开等于函数。
  • “精确”表示没有有限差分的步长截断误差；浮点舍入与基本函数的数值误差仍然存在。
  • ε\varepsilonε 不可逆。高阶信息不影响一阶结果的保证，不覆盖除以 ε\varepsilonε、零点开平方等奇异步骤。
  • 普通光滑规则不处理 ∣x∣|x|∣x∣ 在零点的不可微性。整体函数可微也不保证计算表示中每个基本步骤可微，例如 ∣x∣2=x2|x|^2=x^2∣x∣2=x2；经过 abs(0) 的实现需要重写或明确的额外规则。
  • 保留二阶时可以用 η3=0\eta^3=0η3=0 的截断代数，但一次播种 a+ηa+\etaa+η 的二次系数是 f′′(a)/2f''(a)/2f′′(a)/2，不是未经缩放的二阶导数。
  • 生成函数和对偶数共享系数编码与截断思想；两者不是同一个概念。几何解释也不替代计算规则。

Active Recall

  • Question: 为什么对偶数乘法的第二分量是 ad+bcad+bcad+bc 而不是 bdbdbd？
    • Answer: 一次项来自零次乘一次与一次乘零次；bdbdbd 对应二次项，已被截断。
  • Question: 为什么非零的 ε\varepsilonε 不能做除数？
    • Answer: 它乘任何对偶数都得到实部为零的结果，不可能得到幺元 111。
