In One Sentence

只要集合中有一列互不相同的元素，就可以把这条无限链整体向后移一位、保持其余元素不动，构造它与删除链首后的真子集之间的双射；ZFC 保证每个无限集合都具有这样的链。

Explanation

从 [0,1][0,1][0,1] 到 [0,1)[0,1)[0,1)：只移动一条数列

为什么在 ZFC 中每个无限集合都能使用这个方法

ZFC 包含选择公理；在该框架下，每个无限集合都包含一个可数无限子集。因此可以选出上述互不相同的 ana_nan​，进而得到与真子集等势的双射。

可以从选择函数看出选取过程：对 AAA 的每个非空子集选定一个元素，第一次选 a0a_0a0​，以后从 A∖{a0,…,an}A\setminus\{a_0,\ldots,a_n\}A∖{a0​,…,an​} 中选取 an+1a_{n+1}an+1​。因为无限集合去掉有限项后仍非空，递推不会停止；已取元素被排除，保证各项不同。

这里选择公理用于保证对任意无限集合都能这样选取。对于 R\mathbb RR、[0,1][0,1][0,1] 等已有显式序列的具体集合，不需要为这条构造额外调用选择公理。

没有选择公理时：无限与戴德金无限要区分

以下是为明确边界而补充的整理说明，并非原对话完整展开的内容。

通常“无限”指不与任何有限自然数等势。若一个集合与自己的某个真子集等势，则称为戴德金无限。在 ZF（不加入选择公理）中，可以直接证明以下条件等价：

  1. AAA 包含一个可数无限子集。
  2. AAA 与某个真子集等势。
  3. 存在一个单射 j:A→Aj:A\to Aj:A→A，但 jjj 不满射。

“1 推出 2”就是前面的移位构造；“2 推出 3”把到真子集的双射看作到 AAA 的函数即可。

证明“3 推出 1”：取 a0∈A∖j(A)a_0\in A\setminus j(A)a0​∈A∖j(A)，令 an=jn(a0)a_n=j^n(a_0)an​=jn(a0​)。若 m<nm<nm<n 且 am=ana_m=a_nam​=an​，反复使用 jjj 的单射性消去前 mmm 次迭代，得到

a0=jn−m(a0)∈j(A),a_0=j^{n-m}(a_0)\in j(A),a0​=jn−m(a0​)∈j(A),

与 a0∉j(A)a_0\notin j(A)a0​∈/j(A) 矛盾。因此所有 ana_nan​ 不同，构成可数无限子集。这里只从一个已知非空集合选一个见证 a0a_0a0​，不需要选择公理。

所以，拥有可数无限子集与能移到真子集之间的关系，在 ZF 中已成立；需要留意的是“每个无限集合都拥有这样的子集”这一全称断言。不能在一般 ZF 框架下无条件使用它：不加入适当选择原则时，可以出现无限但戴德金有限的集合，即它们并不与自己的任何真子集等势。完整选择公理足以排除这种情形，但不应把这里所用的较弱全称命题直接说成与完整选择公理等价。

Example

目标中的正整数 1,2,3,…1,2,3,\ldots1,2,3,… 分别来自 0,1,2,…0,1,2,\ldots0,1,2,…；其余目标来自自身。不在链上的负整数、非整数和无理数均保持不动。

对自然数本身，n↦n+1n\mapsto n+1n↦n+1 就是 N→N∖{0}\mathbb N\to\mathbb N\setminus\{0\}N→N∖{0} 的双射。它不是从 N\mathbb NN 到 N\mathbb NN 的满射，因为作为后者时会遗漏 000；同一公式是否满射必须结合指定的陪域判断。

Boundaries and Common Confusions

  • 真包含不必严格更小。 B⊊AB\subsetneq AB⊊A 描述元素包含关系，∣B∣<∣A∣|B|<|A|∣B∣<∣A∣ 描述不存在双射，二者在无限集合上不能混同。
  • 并非每个真子集都等势。 例如 Q⊊R\mathbb Q\subsetneq\mathbb RQ⊊R，但前者可数，后者不可数。这里只保证存在某个真子集，并且在 ZFC 中删除任何指定的单点都不改无限集合的势。
  • 任意删除无限多个点没有同样保证。 从 N\mathbb NN 删除 N∖{0}\mathbb N\setminus\{0\}N∖{0} 只剩一个点，势当然改变。
  • 无限集合不都是同一种大小。 同自身某个真子集等势，不会消除 ℵ0<2ℵ0\aleph_0<2^{\aleph_0}ℵ0​<2ℵ0​ 等不同无限基数。
  • 不能先“执行完所有移位”再得到函数。 分段公式同时规定每个元素的目标；它不是一个做完无穷次搬移才终止的有限程序。
  • 区间映射不是连续性结论。 此处只证明集合双射。对 [0,1][0,1][0,1] 的具体 FFF，例如在 111 处，靠近 111 且不在指定数列上的点保持原值、趋近 111，而 F(1)=1/2F(1)=1/2F(1)=1/2，已经表现出不连续。
  • 不可省略背景公理。 对具体可数链的移位无须选择公理；将结果推广到所有无限集合时，必须说明处在 ZFC 等足够的框架中。

When This Is Useful

用于显式比较开闭端点不同的区间、说明无限集合为何能容纳额外元素，以及识别涉及任意无限集合的论证中隐含的选择原则。
